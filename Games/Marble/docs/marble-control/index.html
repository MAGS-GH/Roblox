Se flowet

Ét loop pr. frame

Alt kører i RenderStepped. Hvert frame læser vi taster, opdaterer hastighed og flytter kameraet.

  1. 1 WASD → rawMove
  2. 2 Pile → kamera yaw/pitch
  3. 3 rawMove → smoothMove
  4. 4 Lerp fart (accel / brake)
  5. 5 Space → hop hvis på jord
  6. 6 Kamera følger kuglen
RunService.RenderStepped:Connect(function(dt)
  updateRawMoveFromKeys()
  updateCameraFromKeys(dt)
  applySmoothDrive(ball, dt)
  applyCamera(ball, immediate, dt)
end)

WASD er kamera-relativ

W betyder ikke “nord i verden” — det betyder fremad ift. hvor kameraet kigger (kun XZ-planet).

Vi bygger en retning: look + right. Diagonal (W+D) normaliseres, så man ikke får √2 fart.

local look = getCameraFlatLook()
local right = Vector3.new(-look.Z, 0, look.X)
local dir = (look * -z) + (right * x)
if dir.Magnitude > 1 then
  dir = dir.Unit  -- max længde 1
end
rawMove = dir

Kernen: smooth velocity

Vi sætter ikke en kraft. Vi sætter AssemblyLinearVelocity direkte og lerper hen imod den ønskede fart — arcade, ikke realistisk fysik.

1. InputSmooth

smoothMove glattes mod rawMove, så start/stop ikke er digitalt.

2. Desired

Ønsket hastighed = retning × MaxSpeed.

3. Accel / Steer

Med input: lerp hen mod desired. Ved fart bruges mindst SteerRate til skarpe sving.

4. Brake

Uden input: lerp mod 0. Aktiv opbremsning — ikke kun friktion.

smoothMove = smoothMove:Lerp(rawMove, expAlpha(InputSmooth, dt))
desired = smoothMove.Unit * MaxSpeed
newHorizontal = horizontal:Lerp(desired, expAlpha(AccelRate, dt))
-- behold vel.Y (hop / gravity)
ball.AssemblyLinearVelocity = Vector3.new(newHorizontal.X, vel.Y, newHorizontal.Z)

Hvorfor expAlpha?

En fast lerp som 0.1 hvert frame bliver hurtigere ved 120 fps end ved 30. Formlen 1 - e^(-rate × dt) giver samme følelse uanset framerate. 

local function expAlpha(rate, dt)
  return 1 - math.exp(-rate * dt)
end

Hop & jord-check

Space sætter et flag. Hoppet sker i loopet, og kun hvis isGrounded finder gulv med raycast under kuglen.

Vi rører kun Y-hastigheden — XZ fra kørslen bevares. 

if not isGrounded(ball) then return end
ball.AssemblyLinearVelocity =
  Vector3.new(vel.X, Config.Marble.JumpSpeed, vel.Z)

Kamera & taster

  • WASD kør
  • Pile orbit-kamera
  • Space hop
  • Enter drej kamera mod mål
  • R respawn (server)

Styringen kører på klienten, fordi du er NetworkOwner af din marble — ingen ventetid på server-roundtrip.
